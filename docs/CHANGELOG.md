 # Changelog

## 1.0.1

- Dispensers with Shears can harvest mature Large Herb, Tobacco, and Chili plants.
- Farmers can pick up and plant Ephedra Seeds.
- Herb Buds and Dried Herb Buds work as Create Potato Cannon ammunition.
- Relaxation now also penalizes ranged attacks against mobs and players.
- Mob equipment definitions now support priorities and replacing vanilla-assigned equipment. See the configuration guide for the data-pack format.
